
# IoT Monitoring System

## Project Overview
An IoT-based Industrial Monitoring System designed to monitor industrial parameters using sensors and a NodeMCU controller.

## Objectives
- Monitor gas levels
- Measure temperature and humidity
- Monitor current consumption
- Detect vibration
- Provide alerts when readings exceed thresholds

## Hardware Components
- ESP8266 NodeMCU
- MQ Gas Sensor
- DHT11 Sensor
- ACS712 Current Sensor
- Vibration Sensor
- LCD Display
- Buzzer
- LED

## Software & Technologies
- Arduino IDE
- Embedded C / C++
- IoT
- Sensor Integration

## Features
- Real-time sensor monitoring
- LCD-based data display
- Buzzer alerts
- LED warning indication
- Industrial safety monitoring

## Applications
- Industrial safety
- Gas leakage detection
- Equipment monitoring
- Smart industrial automation
